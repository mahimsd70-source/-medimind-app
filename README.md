# MediMind.care 💊👨‍⚕️

> Doctors who care like family.

**Live App:** https://medimindapp-sigma.vercel.app

### ✨ Features
- 💊 Smart Pill Scheduler with doctor assignment
- 👨‍⚕️ Top Doctors - Online consultation cards
- 📸 Health Vault - Scan & store prescriptions
- 👨‍👩‍👧‍👦 Family Health Management
- 🎨 Premium UI with glassmorphism & gradients
- 🌙 Offline support - LocalStorage

### 🛠️ Built With
- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion Style UI
- Vercel Deployment

### 🚀 Why I Built This?
Every family struggles to track medicines. MediMind makes it simple - combining doctor care + patient tracking in one beautiful app.
